# Charlie UI: BEFORE score (ux-reviewer, showcase mode)

Date: 2026-10-28. Build: static demo (`tools/build_demo.py --pyodide-dir`), served from `site/`, sample person Alex Rivera.
Bar: Linear / Stripe-dashboard level product polish (stand-in for Build Slate / chaseholroyd.com). Target 8/10.
Screenshots: not committed (they lived in the reviewer's session scratch space). File names below are kept for reference (prefix `m-`=390x844, `d-`=1280x800, `-light`/`-dark`, `-full`=full page).

## Verdict: Needs changes. Overall 5/10

- **Recruiter, phone, 90 s:** sees the sample banner and "Today's ideas", then a wall of option numbers starting with a red "$12,417 max loss". Doesn't learn what Charlie is or why it's clever. The value prop (`brand-sub`) is hidden under 760px.
- **Hiring manager, laptop, 5 min:** the depth is real and the guardrails are visible (good), but each idea card is ~1,150px tall with 9 metric tiles, a chart, a ticket, two lists and a quote, all at the same visual weight. It reads like a solid internal tool, not a polished product.
- **Least tech-savvy user (new investor):** jargon ("~0.20 delta", "IV range", "Short-strike delta", "Expected move ±1σ") before any plain answer to "should I care about this idea?"

What's already good: no console errors, no horizontal page scroll at 390 or 1280, light and dark both work, axe passes (per e2e), the honest-demo banner and back link are there, the disclaimers are everywhere, the color tokens are tidy, and the green accent palette is calm.

## Acceptance criteria for qa-tdd

- CHL-UX1: at 390x844 and 1280x800, the `#chat-form` bounding box doesn't intersect `#footer-disclaimer`.
- CHL-UX2: the Today tab shows, above the first `.card`, text that matches "resume" and "Munger" within the first viewport at 390x844.
- CHL-UX3/4: each `.card` on Today is ≤ 800px tall at 390px with details collapsed; each card has exactly 3 hero metrics and still contains the NFA text outside any closed `<details>`.
- CHL-UX5: every `<text>` in `.payoff` renders at ≥ 11px computed on screen at 390px (getBoundingClientRect height).
- CHL-UX7: footer `scrollHeight <= clientHeight` at 390px.
- CHL-UX10: the paper empty state contains a button that navigates to Today.
- CHL-UX11: after opening the drawer, `document.activeElement` is inside `#drawer`, `#drawer` has `role="dialog"` and `aria-modal="true"`, and Escape returns focus to the opener.
- CHL-UX15: a `:focus-visible` rule exists using `--accent`.
